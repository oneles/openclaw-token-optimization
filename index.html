⏱️ 优化实施步骤
1. 启用上下文修剪 (Context Pruning)
减少发送给模型的历史工具结果，预计节省 30-40% 工具输出 token
"contextPruning": { "mode": "cache-ttl", "ttl": "5m", "softTrimRatio": 0.3 }
2. 配置自动压缩 (Compaction)
长会话自动摘要，保持上下文窗口健康
"compaction": { "mode": "safeguard", "reserveTokensFloor": 20000, "memoryFlush": { "enabled": true } }
3. 优化缓存策略
使用心跳保持缓存"热"，避免重新缓存完整提示
"heartbeat": { "every": "55m" } "models": { "anthropic/claude-opus-4-5": { "params": { "cacheRetention": "long" } } }
4. 切换本地记忆搜索
使用本地嵌入模型，完全消除远程 API 调用
"memorySearch": { "provider": "local", "fallback": "none", "cache": { "enabled": true } }
5. 精简工作区文件
控制 AGENTS.md、SOUL.md 等文件大小
"bootstrapMaxChars": 10000
